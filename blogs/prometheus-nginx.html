    prometheus配置nginx监控

    mousemin 2021/9/29 promethenusnginx

    由于没有能力自己写,去github (opens new window)找到两个方案

    • nginx-module-vts (opens new window)
    • nginx-lua-prometheus (opens new window)

    # nginx-module-vts方案

    • nginx-1.16.1 (opens new window)
    • nginx-module-vts-0.1.18 (opens new window)

    # 安装

    编译nginx将nginx-module-vts模块编译进去

    ./configure --add-module=nginx-module-vts && make && make install
    1

    # 配置

    nginx.conf添加 vhost_traffic_status_zone 示例如下

    http {
    vhost_traffic_status_zone;
    ...
    server {
        ...
        /metrics {
            vhost_traffic_status_display;
            vhost_traffic_status_display_format prometheus;
        }
    }
}
